# Container Loading Decision Support

A graduation project at the University of Jeddah. We are building
an Android app with Flutter to help users plan how to load boxes
into a shipping container.

## First Semester Scope

- Enter container and box dimensions manually.
- Generate a loading plan and check it against the supported constraints.
- Show how much container space is used and which boxes could not be placed.

Camera-based box measurement is planned for the second semester.
